# AI Personal Finance Dashboard

An AI-powered personal finance dashboard that helps users track expenses, analyze spending patterns, visualize financial data, and gain actionable insights through an intuitive interface.

## 🚀 Features

- 📊 Interactive financial dashboard
- 💰 Income and expense tracking
- 📈 Spending analytics and visualizations
- 🤖 AI-powered financial insights
- 🔍 Transaction management
- 📱 Responsive user interface
- 🌙 Modern and clean design

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL (or your configured database)

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Personal-Finance-Dashboard.git
```

### 2. Navigate to the project

```bash
cd AI-Personal-Finance-Dashboard
```

### 3. Install dependencies

```bash
npm install
```

or

```bash
pnpm install
```

### 4. Configure environment variables

Create a `.env` file in the project root and add the required environment variables.

Example:

```env
DATABASE_URL=your_database_url
PORT=5000
```

### 5. Start the development server

```bash
npm run dev
```

or

```bash
pnpm dev
```

## 📦 Build

```bash
npm run build
```

## ▶️ Run Production

```bash
npm start
```
